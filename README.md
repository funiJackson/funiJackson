### What I'm working on

**[Riff](https://app.getriff.app/)** — an AI ghostwriting platform. 490 commits of
production TypeScript, built and maintained end to end and fully remotely: JWT/OAuth
auth, Paddle billing and webhooks, transactional email, and an LLM content pipeline.
*(private repo)*

**[SAGE Guardrail](https://github.com/funiJackson/SAGE-RAG-Guardrail)** — a
deployment-constrained guardrail for RAG content generation. A poisoned web page
shouldn't be able to rewrite a cited report; SAGE sits at the retrieved-content →
generation-prompt boundary and stops it. Ships with a 142-attack corpus, automated
detectors and a capture-once/replay-many harness, so the effect is measured rather
than asserted.

**[Specdev-MCP](https://github.com/funiJackson/SpecMCP)** — MCP tools and Claude Code
slash commands for spec-driven development, with `.sdd` contracts a coding agent has
to keep.

**[Personal Finance Tracker](https://github.com/funiJackson/Personal-Finance-Tracker)**
— receipt photos to a queryable ledger. A vision model extracts the fields, a human
confirms them before anything is written, and Postgres turns them into monthly
spending analytics. Extraction accuracy was checked against 188 photos of real
receipts, not clean synthetic samples.
